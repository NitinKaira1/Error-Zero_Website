# Nitin Kaira — Portfolio

A personal portfolio website designed with a dark Victorian-inspired aesthetic, combining deep emerald tones, warm ivory, and antique gold.

## ✦ Features

- Dark and light theme toggle
- Victorian-inspired typography
- Emerald and antique-gold color palette
- Responsive design
- Minimal left-side navigation
- Projects and skills sections
- Pure HTML, CSS and JavaScript
- Google Fonts: Jim Nightshade + Libre Baskerville

## 🎨 Design

The visual style is inspired by vintage Victorian interiors, botanical illustrations, antique books, and emerald gemstones.

### Dark Theme
- Deep teal / emerald
- Antique gold
- Warm ivory

### Light Theme
- Warm ivory
- Deep emerald
- Antique gold

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts
